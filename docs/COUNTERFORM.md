# Counterform Industrial：美術系統規範（實作版 v1.0）

> 以可信的工業材質呈現不可信的世界，以清楚的幾何呈現不合理的空間，以精密的槍械對比失序的建築。

這份文件是給未來每一張地圖、每一把槍、每一個介面用的規則。所有數值都在 `scripts/style/counterform.gd`，改那一個檔案就會套用到全遊戲。

## 1. 色票

| 名稱 | 值 | 用途 |
|---|---|---|
| 骨灰混凝土 | `#D0C7B8` | 主要結構面 |
| 機械石墨 | `#34383B` | 機械、框架、UI 面板 |
| 氧化赭橙 | `#A65339` | 識別色。只用在建築局部、工業標記、槍械細節、移動路線提示 |
| 灰綠工業漆 | `#777D77` | 工業塗裝、指引 |
| 粉塵白 | `#E9E4D9` | 淺色塗裝、UI 文字 |
| 警示硫黃 | `#D9C75B` | 只用在需要特別辨認的資訊 |

衍生色有中混凝土 `#B4AB9C`、暗混凝土 `#8C857A`、深石墨 `#24272A`、鏽 `#6E3A28`、鋼 `#5D6163`、裸鋼 `#A3A5A3`、黃銅 `#A88B55`、褐色聚合物 `#7E6A52`。

**規則**
- 場景大面積只用灰、灰褐、骨白、石墨和灰綠。
- 橘色和硫黃色的面積要小，要看得出是「標記」。
- 每張地圖可以用 `Counterform.environment(parent, sun_angle, tint)` 的 `tint` 換天空和霧的顏色，材質邏輯不變。

## 2. 材質類別

用 `Counterform.material(kind, color, world_space)` 取得材質。

| kind | 用途 | 特徵 |
|---|---|---|
| `concrete` / `concrete_dark` | 結構 | 板模混凝土：0.75 m 一條板線、3 m 一條施工縫、對拉螺栓孔、細孔、淡水漬。粗糙度約 0.9，不會看起來濕 |
| `paint` | 塗裝鋼 | 半霧面，細微橘皮。世界物件有淡淡髒污，槍械保持乾淨 |
| `oxide` | 氧化金屬 | 鏽斑、粗糙、帶一點金屬感 |
| `bare` | 裸金屬 | 拉絲紋、高金屬度、低粗糙度 |
| `polymer` | 握把、護具、布料 | 低反射，細微表面紋理 |
| `rubber` | 手套、鞋底、墊片 | 最粗糙 |
| `glass` | 特殊用途 | 節制使用，必須有明確用途 |

**規則**
- 世界物件用世界座標三平面投影，大塊物件不會拉伸，相鄰物件的紋理會對齊。
- 槍械用物件座標。
- 不使用高對比、密集或規律的程序紋理。
- 細節分三層：大面乾淨，中層表現結構，小層才是磨損和接縫。

## 3. 幾何語言

- 大型物件先有清楚的體積，再補局部細節。
- 建築可以誇張、斷裂、錯位、懸浮、倒置，但材質和結構要可信。
- 可站立的面、掩體和路線必須一眼看得出來。
- 超現實元素只放在可玩範圍外，或做成不影響判讀的大尺度構圖。

範例見 `Counterform.vista()`：
- 懸浮的巨型混凝土量體
- 倒掛的塔
- 爬到半空、翻轉後繼續往上的樓梯
- 一路延伸進霧裡的鋼構門框
- 以角站立、被不可能的框架貫穿的巨板

## 4. 光照與後處理

- 主光是暖白太陽，有陰影。
- 補光是對側的冷色弱光，讓背光面保留幾何。
- 環境光來自天空。
- 色調映射用 Filmic，有輕微霧氣和很弱的泛光。
- 不使用描邊、像素化、色差、暈影、魚眼或全畫面顆粒。原本的 FAULTPRINT 後處理在這個風格下不會掛上。

## 5. 槍械

- 鋼件是磷化鋼，深色件是黑色陽極。
- 握把和槍托是聚合物。
- 強調件用氧化赭橙或灰綠塗層。
- 管件和黃銅件是裸金屬。
- 槍械保持乾淨精密，不加世界物件的髒污。

## 6. HUD

- 文字是粉塵白。
- 面板是 84% 不透明的石墨色。
- 邊框是 16% 的粉塵白細線。
- 強調色是氧化赭橙。
- 不使用套色偏移字，也不使用粗黑描邊。
- 介面元件都在 `FpUi`，顏色來自 `Faultprint.ui_*`。

## 7. 新地圖檢查清單

1. 呼叫 `Faultprint.environment()`，Counterform 會自動接手。需要的話傳入自己的 `tint`。
2. 結構用 `Geo` 積木，傳入舊的色名（CONCRETE、BONE、SLATE、ORANGE…）。Counterform 會換成對應的材質類別。
3. 在可玩範圍外放至少一組超現實量體。
4. 檢查四件事：可站立面、掩體、路線、敵人都能在暗部辨認，而且不只靠顏色。
