# 角色美術與動畫升級：變更紀錄、測試與待解問題

這份文件是角色升級（6 個階段）的驗收文件：每個階段做了什麼、怎麼重現測試和影片，以及還沒解決的問題。

## 變更紀錄

### Phase 1：盤點
- 盤點舊角色（剛體方塊人）、動畫（程式擺動）、第一人稱手臂、網路狀態、擊殺回放。
- 盤點結果在 Phase 1 文件（專案討論串裡的連結）。

### Phase 2：代表角色（`scripts/actors/body/`）
- **骨架與蒙皮**：24 根骨頭的 Skeleton3D，整個身體加全套裝備是同一張蒙皮網格，共 14 個材質面。
- **製作方式**：全部在 Godot 裡用程式生成，沒有匯入任何外部素材，不需要另外做授權檢查。
- **材質**：布料、尼龍、織帶、皮革、橡膠、皮膚、塗裝硬殼、金屬、鏡片，各有自己的粗糙度和金屬度，低彩度。
- **IK 持槍**：右手抓在每把槍自己的握把點上，左手托在護木下；腳也用 IK 踩地。
- **布娃娃**：11 段剛體驅動骨頭，槍會脫手。

### Phase 3：核心動作（`athlete_motion.gd`）
- **狀態機**：10 種移動狀態，和 Player.Move 一一對應，狀態之間平滑交叉淡入。
- **由真實速度驅動**：
  - 步幅跟著速度變化，腳不會在地上打滑。
  - 轉身時骨盆落後、胸口領先。
  - 加速時前傾，急停時後仰。
  - 落地壓縮的深度隨下墜速度增加。
  - 腳伸不到地面時會踮起腳跟。
- **牆跑**：身體側傾，腳底踩在牆面上（不會穿進牆裡）。
- **蹬牆跳**：靠牆那隻腳留在牆上，蹬直後才離開。
- **重踩**：分成蓄力收腿、直落、著地重壓三段。
- **閃避**：朝實際移動方向做弓步。
- 錄影工具：`tools/motion/`。

### Phase 4：武器動畫（`scripts/weapons/reload_plan.gd`）
- **換彈模板**：共 11 種，依槍身、標籤、彈匣類型自動選擇：
  - 可拆彈匣、側裝彈盒
  - 栓動壓彈夾
  - 左輪
  - 管狀彈倉
  - 折開式
  - 彈鏈
  - 能量匣
  - 料斗
  - 弩
  - 前裝
- **射擊後的動作**：栓動槍每發後拉栓，泵動槍每發後泵動，槓桿槍每發後扳槓桿。
- **1P 與 3P 同步**：第一人稱手臂和第三人稱身體播同一條時間軸，而且都跟著武器自己的換彈計時走。換彈中斷時兩邊同一格停下。

### Phase 5：網路、bot、擊殺回放
- **統一的動作狀態**：玩家、bot、遠端玩家、擊殺回放都用同一份（`CompetitorRig.anim`），內容包括：
  - 移動狀態、俯仰、蹲
  - 牆面法線
  - 換彈剩餘時間、換彈總時間、是否空槍
  - 踢牆次數、開槍次數
  - 是否著地、射速
- **事件用累計次數表示**（踢牆、開槍）：封包掉了或回放跳格，事件都不會遺失。
- **換彈時鐘**：遠端玩家的換彈依擁有者的時鐘推算到當下。
- 擊殺回放會錄下並重播這份動作狀態。
- 角色網格在載入時預先建好，第一個角色出現時從約 300 ms 降到約 1 ms。

### Phase 6：品質與效能
- 量過再優化：
  - 只重算有變動的那段骨頭鏈。
  - 骨頭索引改用快取。
  - 距離鏡頭 35 m 外的角色半頻更新，但遇到踢牆等事件的那一格一定更新。

## 影片驗收

`tools/motion/film.sh <godot> <輸出資料夾> [流程...]`（需要 xvfb 和 ffmpeg），做法是：
1. 用真的 Player 跑固定流程，每格錄下狀態。
2. 讓角色重播這些狀態並拍成影片。

7 段流程：

| 流程 | 內容 |
|---|---|
| locomotion | 走跑、轉身 |
| slide | 滑鏟 → 滑跳 → 落地 |
| wallrun | 牆跑 → 蹬牆跳 |
| dash | 閃避、閃避跳 |
| stomp | 重踩 |
| climb | 攀爬、翻越 |
| fall | 高處落地 |

## 待解問題

- **臉**：只有基本五官，表情不會動。
- **左手手指**：部分角度下手指會陷進護木裡。
- **槍是一整塊模型**：
  - 折開式和左輪是用整把槍傾斜來表現，槍管和彈巢本身不會分開。
  - 栓動槍的槍栓本身不會動，只有手會動。
- **換彈道具**：手上拿的彈殼、快裝器、弩箭只是簡單形狀。
- **影片角度**：
  - 從側面看牆跑，傾斜角度不夠明顯。
  - 重踩著地後馬上彈起，壓縮只看得到 1–2 格。
- **bot**：只有地面和空中兩種狀態，因為 bot 本身不會滑鏟或牆跑。
- **遠端玩家的開槍**：用本機看到的彈道來計數，所以兩台電腦上的拉栓時機可能差一個封包。
- **實機量測**：GPU 成本還沒在實機量。如果 10 人同屏太重，下一步可以加簡化網格（LOD）和遠距離關陰影。
